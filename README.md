# Визитка

Это простой сайт-визитка с адаптивным дизайном.

## Файлы

- `index.html` — главная страница
- `styles.css` — стили сайта

## Как запустить

Просто откройте `index.html` в браузере или используйте локальный сервер, например:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://127.0.0.1:8000`.
