# Візитівка

Це простий сайт-візитівка з адаптивним дизайном.

## Файли

- `index.html` — головна сторінка
- `styles.css` — стилі сайту

## Як запустити

Просто відкрийте `index.html` у браузері або використайте локальний сервер, наприклад:

```bash
python3 -m http.server 8000
```

Потім перейдіть на `http://127.0.0.1:8000`.
